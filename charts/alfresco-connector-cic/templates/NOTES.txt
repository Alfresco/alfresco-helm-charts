If live-ingester is enabled, add the following properties to your Alfresco
repository instance under additionalGlobalProperties. These use the hxi.*
namespace because they configure the Alfresco Repository's HXI extension:

  hxi.auth.providers.hyland-experience.token-uri={{ .Values.cic.hxAuthTokenUrl }}
  hxi.auth.providers.hyland-experience.environment-key={{ .Values.cic.hxEnvKey }}
  hxi.auth.providers.hyland-experience.client-id={{ .Values.cic.hxClientId }}
  hxi.auth.providers.hyland-experience.client-secret={{ .Values.cic.hxClientSecret }}
  hxi.connector.source-id={{ .Values.cic.hxAppSourceId }}

Consult your Hyland Experience portal for the values of:
  hxi.discovery.base-url
  hxi.knowledge-retrieval.url
